# HiveCode

HiveCode 是 [Orca](https://github.com/stablyai/orca) 的产品分支，专注于在本地和远程 worktree 中并行开展智能体开发。桌面端和移动端保留必要的上游协议与兼容别名，但产品名称和用户可见身份均为 HiveCode。

## 当前状态

此仓库目前是工程分支，尚未配置独立的公开发行渠道、官网、下载地址、云服务、支持或社区入口。请勿将 Orca 的上游发布链接当作 HiveCode 的安装说明。

## 兼容性

为了兼容已有安装和持久化数据，`orca`、`orca-ide`、`orca://`、`ORCA_*`、旧 `.orca` 目录以及上游插件标识仍会保留。这些是兼容接口，不是 HiveCode 的产品品牌。

当前项目说明请参阅[根 README](../../README.md)，贡献与上游同步边界请参阅[贡献指南](../../.github/CONTRIBUTING.md)。

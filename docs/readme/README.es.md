# HiveCode

HiveCode es un fork de producto de [Orca](https://github.com/stablyai/orca), centrado en el desarrollo paralelo con agentes en worktrees locales y remotos. Los clientes de escritorio y movil conservan los protocolos y alias de compatibilidad necesarios, pero la identidad visible del producto es HiveCode.

## Estado actual

Este repositorio es por ahora un fork de ingenieria. Todavia no tiene canales publicos propios de distribucion, sitio web, descargas, servicios en la nube, soporte ni comunidad. No uses los enlaces de publicacion de Orca como instrucciones de instalacion de HiveCode.

## Compatibilidad

Los identificadores `orca`, `orca-ide`, `orca://`, `ORCA_*`, los directorios heredados `.orca` y los identificadores de plugins upstream se conservan para no romper instalaciones ni datos existentes. Son superficies de compatibilidad, no la marca del producto.

Consulta el [README principal](../../README.md) para el estado actual y la [guia de contribucion](../../.github/CONTRIBUTING.md) para los limites de sincronizacion con upstream.

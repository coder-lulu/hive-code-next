# HiveCode

HiveCode는 로컬 및 원격 worktree에서 에이전트 개발을 병렬로 진행하는 데 초점을 둔 [Orca](https://github.com/stablyai/orca) 제품 fork입니다. 데스크톱과 모바일 클라이언트는 필요한 업스트림 프로토콜과 호환 별칭을 유지하지만, 사용자에게 표시되는 제품 이름과 정체성은 HiveCode입니다.

## 현재 상태

이 저장소는 현재 엔지니어링 fork이며, 독립적인 공개 배포 채널, 웹사이트, 다운로드, 클라우드 서비스, 지원 또는 커뮤니티 주소가 아직 구성되지 않았습니다. Orca의 업스트림 릴리스 링크를 HiveCode 설치 안내로 사용하지 마세요.

## 호환성

기존 설치와 영구 데이터를 손상시키지 않도록 `orca`, `orca-ide`, `orca://`, `ORCA_*`, 기존 `.orca` 디렉터리 및 업스트림 플러그인 ID를 유지합니다. 이는 호환성 표면이며 HiveCode 제품 브랜드가 아닙니다.

현재 상태는 [루트 README](../../README.md)를, 기여 및 업스트림 동기화 경계는 [기여 가이드](../../.github/CONTRIBUTING.md)를 참조하세요.

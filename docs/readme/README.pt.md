# HiveCode

HiveCode e um fork de produto do [Orca](https://github.com/stablyai/orca), focado em desenvolvimento paralelo com agentes em worktrees locais e remotos. Os clientes desktop e mobile preservam os protocolos e aliases de compatibilidade necessarios, mas a identidade visivel do produto e HiveCode.

## Estado atual

Este repositorio ainda e um fork de engenharia. Ele nao possui canais publicos proprios de distribuicao, site, downloads, servicos em nuvem, suporte ou comunidade. Nao use links de lancamento do Orca como instrucoes de instalacao do HiveCode.

## Compatibilidade

Os identificadores `orca`, `orca-ide`, `orca://`, `ORCA_*`, os diretorios legados `.orca` e os IDs de plugins upstream sao mantidos para nao quebrar instalacoes e dados existentes. Eles sao superficies de compatibilidade, nao a marca do produto.

Consulte o [README principal](../../README.md) para o estado atual e o [guia de contribuicao](../../.github/CONTRIBUTING.md) para os limites de sincronizacao com upstream.

# HiveCode

HiveCode は、ローカルおよびリモートの worktree でエージェント開発を並列実行することに重点を置いた、[Orca](https://github.com/stablyai/orca) のプロダクト fork です。デスクトップ版とモバイル版は必要な上流プロトコルと互換エイリアスを維持しますが、ユーザーに表示される製品名とアイデンティティは HiveCode です。

## 現在の状態

このリポジトリは現在、エンジニアリング fork です。独自の公開配布チャネル、Web サイト、ダウンロード、クラウドサービス、サポート、コミュニティ窓口はまだ設定されていません。Orca の上流リリースリンクを HiveCode のインストール手順として使用しないでください。

## 互換性

既存のインストールや永続化データを壊さないため、`orca`、`orca-ide`、`orca://`、`ORCA_*`、従来の `.orca` ディレクトリ、上流プラグイン ID は保持されます。これらは互換性のための識別子であり、HiveCode の製品ブランドではありません。

最新の状態は[ルート README](../../README.md)を、コントリビューションと上流同期の境界は[コントリビューションガイド](../../.github/CONTRIBUTING.md)を参照してください。

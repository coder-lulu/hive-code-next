## Delivered behavior and corrections

- Desktop, Electron `--serve` and Node-only `orcad` install the same Presence and Host. Identity, local authenticated claim/status/reset, readiness and shutdown use existing runtime ports. The single `HIVE_RELAY_V2_HOST_ENABLED` switch defaults false; `HIVE_RELAY_REGION` specifies placement. No separate development/test editions; existing P2 public configuration is preserved.
- Independent Hive authorization, broker and control/data sockets preserve legacy paired-device v1 endpoint, credentials, pools and recovery state. Persistent X25519 Host identity is separate from Runtime Ed25519 proofs. Only controlLease reaches Cell; relayToken goes only to Director.
- Cloud permits exact-CAS rebinding of the same key after legitimate boot/lease rotation while fencing old assignments and rejecting revoked identities or key rollback. Explicit current-owner control-lease refresh preserves generation and retries the same reservation. Assign retains takeover semantics; consumed authorization JTIs cannot retake control. Deploy Cloud migration `V2B079` and the corrected exact `/v1/assign` proxy route before enabling P3 against that server.
- Account authentication carries ticketSecret only inside E2EE, checks client-key binding and consumes once per physical connection. RPC requires both ACTIVATE=APPLIED and continuous ACK. Late responses, cancellation, changed authority and restart fail closed; late APPLIED creates a versioned CLOSE. Revoke uses command ACK, never a fabricated CLOSE/ABANDON.
- Real integration exposed full heartbeat responses being passed into the strict outbox ACK validator; Host now passes only its two ACK fields. Assignment, generation and Cell incarnation fence response delivery. Capability follows control ACK. Commands advance ACK one at a time; obsolete assignment commands do not revoke current sessions.
- Atomic durable outbox caps at 256 transitions and 128 per batch. Recovery cannot resurrect sockets; boot retirement preserves bounded fence evidence without fabricated ACKs. Corrupt, mismatched and symlinked storage fails closed.
- Absolute, idle and authority timers close without traffic; monotonic time prevents clock rollback extending authority. Single-use data attach has no connTicket retry. Frame limits, 32 simultaneous data connections and 512 remembered connection IDs bound admission state.
- Account RPC revalidates input, binary and delayed output, reuses existing dispatch and connection-owned subscription cleanup, and refuses late handler registration. Admission caps: 128 pending requests per connection, 512 across Account connections, 4 MiB per JSON request, 64 MiB pending payloads, reusing existing constants. Serialized broker retry has a 250 ms floor, bounded exponential jitter and honors Retry-After.
